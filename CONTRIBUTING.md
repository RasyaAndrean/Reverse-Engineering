# Contributing

Terima kasih sudah tertarik untuk berkontribusi! Repo ini terbuka untuk siapa saja yang ingin membantu atau menambahkan materi.

## Cara Berkontribusi

### Melaporkan Kesalahan
- Buka [Issues](https://github.com/RasyaAndrean/Reverse-Engineering/issues)
- Jelaskan kesalahan yang ditemukan dan di file mana
- Kalau bisa, sertakan koreksi yang benar

### Menambah Materi
1. Fork repo ini
2. Buat branch baru (`git checkout -b tambah-materi-xyz`)
3. Tambahkan materi kamu
4. Pastikan mengikuti struktur folder yang sudah ada
5. Buat Pull Request dengan deskripsi yang jelas

### Menambah Code / Script
- Semua code masuk ke folder `scripts/` dengan subfolder yang sesuai
- Sertakan komentar yang menjelaskan apa yang code lakukan
- Kalau code butuh dependensi, sebutkan di file atau komentar

## Panduan Penulisan

- Gunakan Bahasa Indonesia untuk catatan dan penjelasan
- Nama file gunakan huruf kecil dan strip (`contoh-nama-file.md`)
- Sertakan referensi kalau mengambil materi dari sumber lain
- Format file: Markdown (`.md`) untuk catatan, sesuaikan untuk code

## Code of Conduct

- Semua materi harus untuk tujuan **edukasi**
- Jangan submit malware asli atau exploit berbahaya
- Hormati kontributor lain — kita semua di sini untuk belajar
