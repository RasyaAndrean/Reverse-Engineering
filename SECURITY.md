# Security Policy

## Tujuan Repo

Repo ini dibuat **murni untuk tujuan edukasi**. Semua materi, teknik, dan code yang ada di sini ditujukan untuk belajar reverse engineering secara legal dan etis.

## Disclaimer

- Semua teknik yang didokumentasikan hanya boleh digunakan pada software yang kamu miliki atau punya izin untuk dianalisis
- Jangan gunakan pengetahuan dari repo ini untuk aktivitas ilegal (pembajakan, penyebaran malware, unauthorized access)
- Analisis malware harus dilakukan di **lingkungan terisolasi** (VM dengan snapshot)

## Melaporkan Masalah Keamanan

Jika kamu menemukan konten di repo ini yang berpotensi berbahaya atau menyalahi aturan:

1. **Jangan** buka public issue
2. Hubungi saya langsung via email: rasyaandrean@outlook.co.id
3. Jelaskan konten yang bermasalah dan alasannya

## Praktik Keamanan yang Diikuti

- Tidak menyimpan malware sample asli di repo
- Binary/executable di-exclude via `.gitignore`
- Tidak menyimpan credentials, API keys, atau data sensitif
