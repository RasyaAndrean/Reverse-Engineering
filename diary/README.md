# Diary

Catatan setiap kali push — apa yang dipelajari, eksperimen yang dilakukan, dan hal-hal menarik lainnya.

Setiap push akan membuat subfolder dengan format tanggal `DD-MM-YYYY`.

```
diary/
├── 09-04-2026/
│   ├── catatan-1.md
│   └── catatan-2.md
├── 10-04-2026/
│   ├── catatan-1.md
│   ├── catatan-2.md
│   └── catatan-3.md
└── ...
```

## Format Penulisan

Setiap `catatan.md` menggunakan format:

```markdown
# Catatan ke-1 — Judul Singkat

## Apa yang dilakukan
- ...

## Apa yang dipelajari
- ...

## Catatan tambahan
- ...
```
